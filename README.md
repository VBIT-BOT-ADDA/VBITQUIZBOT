## ✨ Features
- 📝 **Easy Quiz Creation:** Create interactive multiple-choice quiz polls with custom timers and answer shuffling.
- 🍃 **MongoDB Integration:** Permanent cloud storage for quizzes, users, and groups.
- 📢 **Broadcast System:** Send announcements to all registered users and groups with `/broadcast`.
- 📊 **Real-time Statistics:** Track live user and group analytics with `/stats`.
- ⚡ **Multi-Platform Deployment:** Ready for Heroku and Linux VPS deployment.
